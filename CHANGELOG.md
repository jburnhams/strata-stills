# Changelog

Newest first, grouped by day. One entry per change, in the same commit or PR as the change.

## 2026-11-14

**strata-python 0.2.1 from PyPI, and its web, CLI, OS and test pieces adopted (branch `claude/project-thread-k3276m`, PR #101)**
Jonathan asked to upgrade to the latest strata-python, through PyPI, and use its features fully. The PR started on 0.2.0 (0.2.1's release had failed on its token); once Jonathan fixed the token and 0.2.1 reached PyPI, its test helpers and extras were adopted too. `strata_python.db` is left for issue #102 (it changes the service environment).

- `pyproject.toml`, `uv.lock`: `strata-python>=0.2.1,<0.3` from PyPI (was a git source tracking main); `fastapi`, `uvicorn`, `pydantic` and `pytest` dropped from the app's own list, and the dev group's ruff, pyright, ty, httpx and pytest plugins replaced by `strata-python[dev]` (strata-python brings them at the gate's versions). The plugin is configured with `strata_env_prefix = "STRATASTILLS"`, `strata_tuning_vars` and `strata_env` (projects folder, NSFW, lease and AI off). `-p no:strata_python_db` in `addopts`: its database plugin turns itself on when SQLAlchemy is installed (omarchy-db brings it) and adds a second `--pg`, so it stays off until #102.
- `tests/conftest.py`: the hand-written `isolated_env`, `no_network` and `pytest_collection_modifyitems` removed in favour of the plugin's (the `integration` marker entry in `markers` too). The plugin's app home is `<env>/app-home` (was `<env>/stratastills-home`).
- `tests/integration/conftest.py`: `cli` and `cli_subprocess` are `strata_python.testing.run_cli` and `run_module` (its `Result` class removed; `CliResult` has the same `stdout`, `stderr`, `code`, `out`).
- `src/stratastills/server/app.py`: `web.base_app` (adds `GET /api/health`), `web.add_web` replaces the `/` route and the `/assets` mount (the page is now served at every non-API path with a relative `<base href>`, and files beside `index.html` at their name), and `web.serve` replaces the uvicorn wrapper. The settings routes stay: strata-python's `Settings` holds strings only and `source_roots` is a list (strata-python#10).
- `src/stratastills/cli.py`: `serve` through `cli.add_serve`. `doctor` stays our own (it checks the GPU, cuDNN and ffmpeg; strata-python#15).
- `scripts/hash_new.py`: CPU priority through `strata_python.oslib.lower_priority`; ionice stays local (strata-python#12). `scripts/read_meta.py` and `hash_to_jsonl.py` keep their copies: they run on the standard library alone.
- `tests/unit/test_server.py`: **new** test of the health route and the page at a screen path; the report traversal check now asserts the secret is not served (the client normalises `/report/../secret.txt` to `/secret.txt`, which the page answers).
- `.github/workflows/upgrade-strata-python.yml`: **removed**; dependabot's uv entry moves a PyPI dependency within its cap. `AGENTS.md`, `tests/README.md`: what comes from strata-python and what is not adopted yet, and why.

## 2026-11-09

**Move the Python side to uv, ruff, pyright and the shared strata-python gate (branch `claude/project-thread-iw7199`)**
Jonathan asked for every Python project to use the same tooling as [python-app-template](https://github.com/jburnhams/python-app-template): uv, ruff with `ruff format`, pyright and ty, one `scripts/check` gate, and dependencies kept current. Behaviour of the program is unchanged.

- `pyproject.toml`, `uv.lock`: **new** `[project]`, a `dev` group (test tooling, plus the database packages, so `tests/unit/db` runs everywhere instead of skipping), `vision` and `research` groups, git sources for `strata-python`, `omarchy-db` and `strata-models-client`, tool configuration (ruff `E,F,I,B,UP,SIM,RUF,C4,PT,S,TID` with `pytest.importorskip` banned, pyright strict ratchet starting at `__init__.py`, ty). `requirements*.txt`: **removed**. torch is deliberately **not locked**: the right build depends on the card (`scripts/setup_torch.py`), so CI installs the CPU build after `uv sync` (`.github/actions/torch-cpu`, **new**) and the lock holds no CUDA wheel.
- ruff: line length 120 (was 400) and `ruff format` over `src`, `tests` and `scripts` (a mechanical, behaviour-free rewrite of 181 files), import sorting, and the rule set above. B904, B905, RUF059, B023, B007, F841, C416 and a few S rules are ignored for the existing code with a reason in `pyproject.toml`; B023 and F841 are the ones to clean first, they can hide bugs.
- `pyproject.toml` coverage floor 89 -> 88 (correction to the "only ratchets up" rule, with no test removed): `ruff format` splits the one-line `if x: return y` of the old dense style into two lines, and coverage counts lines, so the same unexecuted branches count twice (3490 -> 5485 statements; 90.9% -> 88.8% on the same 480 tests). Ratchet it up from here.
- `tests/**`: `pytest.importorskip("torch" | "spandrel" | "omarchy_db" | "pgvector")` replaced by plain imports, so a missing dependency fails the test instead of skipping it (CI installs them). Still skipped, deliberately visible in `-ra`: the CUDA and MPS tests (no such device on a runner) and the denoise tests that need downloaded weights; making those explicit switches is a follow-up.
- `tests/unit/db/test_mapping.py`, `test_nsfw_store.py`: with the database packages now installed, these tests ran on Windows for the first time (before, CI skipped the whole folder) and 5 failed there: the fixtures are POSIX paths (`/data/raw/...`) and the code normalises with `os.path`. They are skipped on Windows with a reason (`skipif`), to be rewritten with `tmp_path`; they pass on Linux and macOS.
- `.github/workflows/unit.yml`, `integration.yml`, `database.yml`: uv; `strata-check --fast` once on Linux 3.13; current action versions. `upgrade-strata-python.yml`: **new**, weekly PR that moves the library pin after the gate. `.github/dependabot.yml`: **new**, daily, minor and patch grouped, no ignores, for Actions, npm (`/web`) and uv.
- `scripts/check`: **new**. `scripts/setup_env.sh`, `setup_env.ps1`: build the environment with uv (`uv venv --seed`, `uv sync --locked --no-dev --inexact`, then `setup_torch.py`); `--inexact` keeps pip and the torch build that was just installed.
- `README.md`, `AGENTS.md`, `tests/README.md`, `tests/unit/README.md`, messages in `cli.py` and the store modules: commands for uv.
- Not done: `strata_python`'s settings, server skeleton and `oslib` are not adopted here (this app has its own settings with source roots and no `oslib`), and the strata-python pytest plugin is not enabled because `tests/conftest.py` already isolates the home, projects folder and network; both are follow-ups.
